# ELMS Fantasy Basketball

ELMS Fantasy Basketball is a personal fantasy basketball analytics and decision-support application designed for use with my own Yahoo Fantasy Basketball league.

The project combines Yahoo Fantasy Sports league data with external NBA statistics, schedules, injuries, projections, and player trends to generate customized fantasy basketball recommendations.

## Planned Features

- Yahoo Fantasy league integration
- League settings and scoring-category analysis
- Live draft recommendations
- Category-based roster construction
- Player valuation customized to league settings
- Waiver-wire analysis
- Weekly streaming recommendations
- Schedule optimization
- Injury replacement analysis
- Matchup category projections
- Trade analysis
- Opponent roster monitoring
- Historical league-state tracking

## Yahoo Fantasy Sports API Usage

The application is intended initially for personal and single-league use.

Yahoo Fantasy Sports API data may include:

- League settings
- Scoring categories
- Teams
- Rosters
- Players
- Draft results
- Standings
- Matchups
- Free agents and waiver players
- League transactions

Initial integration will be read-only. The application will use Yahoo data to generate analytics and recommendations and will not automatically execute roster transactions.

## Project Status

Early development / prototype.

## Goal

The goal of the system is to answer one central question:

> What available move gives my fantasy basketball team the highest probability of winning the league?

Rather than simply ranking players independently, recommendations will consider roster composition, category strengths and weaknesses, positional needs, schedule, opponent matchups, injuries, and available alternatives.
